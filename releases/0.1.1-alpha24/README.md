# Commons 0.1.1-alpha24 — Quiosc en valencià

Integra Quiosc amb els idiomes i la preferència compartida de Commons:
valencià, català, castellà i anglés. Traduïx textos, avisos de seguretat, estats,
motius i errors. El canvi d’idioma conserva equips seleccionats, URL i sessió.

Es reconstruïx només el portal. API, administració i Play conserven el contingut
de les imatges alpha23. Digests i procedència en `images.json`.

Validació: 22 proves d’interfície i idiomes en escriptori i mòbil, construcció
de la imatge i prova Docker aïllada aprovades. Quiosc continua desactivat fins
que es configure Epoptes; no hi ha canvis en les capacitats de restricció.
