# Commons 0.1.1-beta4-candidate7

Incorpora els últims canvis del peu comú en Commons, Rebost i Llibres, la
correcció del xip en la portada pública i la retirada de les maquetes antigues
dels taulers en la web. Els accessos continuen dirigint als taulers reals de
Commons. Es conserva tota la integració de Banc i la correcció de pujada C6.

- Portal amb el peu: 362 proves de navegador correctes.
- Web actual: 60 proves correctes, inclosa la còpia canònica del CSS.
- Llibres: 29 proves de peu, idioma, biblioteca i aplicació Vue correctes;
  cobrixen quatre idiomes i pantalles estretes.
- Els dos nous continguts d’imatge passen l’auditoria de rutes privades.

Només canvien les imatges de Portal i Llibres respecte de C6. Les 13
referències estan fixades en [images.json](images.json).
