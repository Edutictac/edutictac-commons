# Informació per a les famílies

EduTicTac és un conjunt d'eines educatives dissenyades per minimitzar la
informació personal de l'alumnat.

Per participar en algunes activitats, l'alumne/a pot rebre un **codi** aleatori
(per exemple `K7P`) i un **PIN**. Aquest sistema permet conservar puntuacions i
progrés **sense** que l'alumne/a haja de donar el seu nom ni cap identificador
del centre.

## Què es pot guardar?

- El codi EduTicTac.
- La puntuació o el progrés d'una activitat.
- Una sessió tècnica perquè no calga introduir el PIN cada vegada.

No es guarden el nom, el correu ni cap dada d'identificació de l'alumne/a dins
del stack. El centre pot conservar, fora del sistema, la correspondència entre
el codi i l'alumne/a si la necessita per a l'activitat educativa.

## Què veuen els altres?

En els rànquings, la resta de participants veuen només el **codi**, no el nom
real. Els rànquings no són pàgines públiques obertes: només són visibles per a
l'alumnat amb credencial o el professorat autenticat.

## El PIN és privat

El PIN no apareix en cap rànquing i no s'ha de compartir.

## El professorat

El professorat pot saber quin alumne/a correspon a cada codi si ho necessita
per a l'activitat, però aquesta relació no s'introdueix a EduTicTac.

## Durant quant de temps?

La durada de les credencials i de les puntuacions la defineix el centre. En una
prova o pilot, el centre hauria d'indicar quan revisarà o eliminarà les dades.

## Dubtes o exercici de drets

Com que EduTicTac no guarda el nom real de l'alumne/a, qualsevol petició sobre
les dades s'ha de canalitzar a través del centre, que és qui pot saber quin codi
correspon a cada alumne/a.
