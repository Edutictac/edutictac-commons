# Llicències dels editors opcionals

Blocs i Llibres es distribuïxen com a imatges separades, amb les seues llicències
i avisos originals; no se substituïxen per la llicència del portal.

| Component | Llicència / font |
|---|---|
| EduTicTac Blocs | GPL-3.0-only; https://git.edutictac.es/Edutictac/edutictac-blocs |
| EduTicTac Llibres i motor eXeLearning | AGPL-3.0-or-later; https://git.edutictac.es/Edutictac/edutictac-llibres |
| iDevice Slide | CC BY-SA 4.0 |
| Fabric.js, Vue, fflate | MIT |
| DOMPurify | MPL-2.0 o Apache-2.0 |

El manifest de cada versió registra els commits i digests corresponents.
Llibres oferix el seu codi font i instruccions des de «Sobre Llibres», incloent
Dockerfile.local i la configuració local. El motor eXe conserva els fitxers i
avisos de la distribució oficial verificada per SHA-256.

Les imatges dels catàlegs conserven autoria, font i llicència. El catàleg Scratch
utilitzat pel Rebost inclou CC BY-SA 2.0 i els crèdits corresponents; la seua
reutilització en llibres incorpora els crèdits i fonts originals al projecte.
